## 版本与运行边界

本地 Git 提交和交付包是可复查快照，正式线上版本仍需部署后冻结。实际 commit 与 zip 哈希保存于不纳入 Git 的 `releases/release-info.json`，避免提交内自引用。打包后可用 `git rev-parse HEAD`、`git status --short` 核对本地版本。

`.gitattributes` 禁用 Git 自动换行转换，保留证据与源码的原始文件字节，避免跨平台检出使 SHA-256 不一致。原客服文件已有的末尾空行及 Markdown 双空格换行保留，不为本轮收尾改写历史内容。

当前运行镜像仍是之前构建的 `tracememory:v0`。本轮只修改离线评测和交付工具，API 实现/迁移未改变；镜像内旧评测器未随文件更新。严格复查在本地执行，正式上线前必须用最终源码重新构建并记录镜像 digest，不能声称当前容器已经运行新提交的全部文件。标准 Docker 构建需可用的依赖下载网络；本地离线构建需要未包含在源码包中的 wheelhouse。

跨多个无 timestamp 的 Add，content 尚无会话持续写入顺序；每请求 ordinal 不能区分新旧写入。邻近上下文恢复、事实版本治理、复杂多跳、弃检策略都未验证。它们是已披露的效果限制，不是冒充已完成的改进。
