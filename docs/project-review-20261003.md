## 与最初目标相比仍需后续完成

1. **正式检索性能验收**：持续负载、逐级并发和服务端资源记录；200+ QPS、P99＜500ms 仍是待测目标。
2. **缓存及失效策略**：当前仅缓存 BGE 实例，没有查询结果/答案缓存，因此没有“缓存命中与未命中”性能对照。
3. **业务适配与归属校验**：订单和退款仍直接读取模拟字典；尚无 BusinessRepository、商品数据库查询、独立物流查询和演示用户订单归属校验。未知单号不回退 FAQ 不能替代鉴权。
4. **语义质量**：固定集自动检查已在历史版本达到 46/46，但仍需要条件完整性断言、独立问法和人工复核，不能写成回答准确率 100%。
5. **独立能力验收**：本次标记辅助完成；用户应独立解释一次路由选择、指标分层与故障定位，并修改一个边界用例。

项目当前业务部分是本机模拟客服，`handoff` 仅提示人工，没有真实工单。通用检索使用单路密集向量，业务优先＋FAQ 回退可以作为本项目混合查询路线，但尚未实现 BM25＋向量的稀疏/稠密融合检索。真实鉴权、生产 SLA、人力节省和外网部署不属于已完成成果。
