## 2. 代码行为与配置

`store.py` 在幂等请求锁之后取得 user/session 锁，事务内分配 `received_ordinal`。一个请求的消息连续编号，重试不占新编号。接收顺序不等同源顺序，跨会话也不虚构统一源顺序。入库时间使用数据库 `stored_at`，消息时间保留原 `timestamp`，事件时间留在原文。

`002_memory_order.sql` 按 stored_at/request/ordinal 确定性回填，`order_basis=legacy_ingest_reconstructed`。相同入库时间不足以恢复真实先后。新代码要求 schema=2；迁移尚未在真实 PostgreSQL 跑过，离线通过不是部署完成。迁移保持旧原文、ID、向量及嵌入签名，API 与 schema 需一起升级。

新 content 前缀包含角色、消息时间、会话/请求、请求内序号、接收序号、入库时间、偏移和时间语义。下游仅读取 content 也能取得语境。来源审计兼容旧格式并严格核查新前缀；入库时间只校验格式，不能仅从输入证明数据库时钟，仍需实际数据库记录。

BM25 保留拉丁编号和中文二元词项词频，使用 IDF 和长度归一化（k1=1.2,b=0.75）。真实服务按用户精确扫描，成本随该用户块数增长。窗口仅扩展同用户同会话相邻接收序号及同消息切片，按 ID 去重。相关片段继承种子排名分，不声称它自身的 cosine 分。预算包含前缀，只选择完整原文切片。

默认继续 vector、窗口关闭、预算不限、门槛关闭：

```text
MEMORY_RETRIEVAL_MODE=vector  # vector / hybrid / bm25 / hybrid_bm25
MEMORY_NEIGHBOR_WINDOW=0
MEMORY_SEED_LIMIT=20
MEMORY_EVIDENCE_BYTES=0
MEMORY_MIN_SIMILARITY=
MEMORY_CHUNK_TARGET_BYTES=400
MEMORY_CHUNK_OVERLAP_BYTES=60
MEMORY_IMAGE=tracememory:v2-local
```

旧 `*_TOKENS` 仍作为字节预算的兼容别名；等值改名不改变签名。400 字节不是 400 tokens。选择器不理解任意敏感属性，预算不能替代披露控制。

## 3. 数据与答案判分

旧 `memory_cases_dev.jsonl` / `memory_cases_holdout.jsonl` 及历史输出不改写。补全版独立存为 `memory_cases_v2_dev.jsonl`（60）和 `memory_cases_v2_holdout.jsonl`（40）。新版本移除原占位选项；20 道单选有可匹配选项，其余采用对应原生合同。

`memory_challenge_v2_dev.jsonl` / `memory_challenge_v2_holdout.jsonl` 各 16 个节点/问题，每项能力都有专门情境。开发/留出每用户有 300/1000 条相似干扰，另含其他用户材料；留出的人物、场馆、课程、事件、背景和规则另行编写。哈希在 `evals/memory_challenge_v2_manifest.json`。未基于留出调整阈值或运行配置；新增 seed20 对照是返回量诊断，不把作者可见留出包装成盲测。

合计 132 题：单选20、严格JSON102、序列4、开放rubric4、多选2。题量仍有限，不据此重新给七项能力打满分。

`memory_answer_eval.py` 将 Answer/Judge 放在服务之外。Answer 只接收问题、选项和检索原文，不接收 gold/rubric。保存答案、状态、引用、题型、理由、模型/提示词/解析器版本和数据/检索哈希。检索失败、生成失败、Judge失败、正常答错和正常空证据分开统计。

- 单选字母正确；多选须完整集合，无重复、多选或漏选。
- 排序须完整且顺序正确；JSON 类型严格，布尔不能冒充数字。
- rubric 每项均须满足，Judge布尔类型、ID集合和理由须完整。
- 误拒答、错误允许披露、无关合成敏感标签和伪造引用失败。
- 本地按题等权，全部题分将运行失败计0，另报完成题分及完成率；不是官方Overall。

判分器已通过离线合同/反例检查，尚无新候选模型答题成绩。回放/手写fixture不能称真实模型结果。[官方平台分工](https://agentmemoryleaderboard.ai/api-guide)

## 5. 无密钥复现

在已安装项目依赖的Python环境，从项目根目录运行：

```powershell
python scripts/run_memory_offline.py
```

运行器读取固定题目，不重新生成留出；每次创建新目录，显式禁用数据库/付费测试开关，不读取环境文件。本机旧`.venv`无法启动，本轮使用桌面Python3.12及已有`.test-deps`，未安装新依赖。同一桌面环境可运行：
